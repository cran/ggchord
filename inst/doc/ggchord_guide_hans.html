ggchord：弦图、共线性图与质粒图教程

本教程与英语教程、网站从同一组来源生成。vignette 渲染时只展示代码，不自动执行；共享文档脚本直接验证相关例子。示例优先使用随包数据和有来源的原始记录；人为构造的诊断错误会明确标注。每章提供本页准备代码；第一次使用请从首图教程开始。

1.1 输入表与字段含义

先认识表格，再决定使用哪些图层。弦图是ggchord最早的核心视图；早期工作流围绕BLAST比对表展开，因此保留了紧凑的BLAST风格字段。这里的“多序列比对弦图”展示多条序列间已有的区间比对，绘图本身不执行多序列比对算法。

三张表的最小形状

表 必需列 每行的含义
seq_data accver, length 一条序列及其完整长度，bp
ribbon_data qaccver, saccver, qstart, qend, sstart, send 两条序列上的一对已有比对区间
gene_data accver, start, end, strand 一个有已知正负链的基因区间

只画骨架时，后两张表都不需要。通用注释可保留未知链，请使用 geom_feature()，不要冒充有方向的基因。

名称与可选列

accver 源于 accession.version，但值可为任意稳定字符串，例如自己的contig名称；不会自动添加或删除版本号。q 是query，s 是subject，所以 qstart 是query端起点。两个标识都必须能在序列表中找到。

pident 是百分比相似度，仅映射或筛选相似度时需要；比对表的 length 是比对长度，序列表的 length 是完整序列长度，二者不能混用。evalue、bitscore、qlen、slen 按分析需求保留。基因的 anno 是可选注释文字；要画标签时提供它。其他类别列可供 aes() 映射，不是强制输入。

避障方式为何看起来不同

link_avoid = "uniform" 在整个端区间留统一空隙；"smooth" 只在特征附近平滑退让，形成局部缺口；"none" 不做特征避障。link_gap = NULL 才启用自动规则，给出固定数值会覆盖自动间距。避障检测箭头/特征几何，不避让文字，也不会自动绕过跨行连接途经的整条中间序列。

筛选保留满足已声明阈值的观测；互惠重叠去重选择已有代表观测，不累加相似度； 合并把邻近兼容区间组合为显示外包范围；聚束按邻近 query/subject 位置形成汇总。 逐步检查 $report 和源行成员，特别注意冲突的额外元数据。 合并或聚束范围不是重新计算的核苷酸比对，估计长度保留标记，不凭空生成相似度。

密度是显式统计

stat_ribbon_density() 映射计算后的密度，stat_ribbon_bundle() 在 build 时执行 明确聚合，普通区间连接几何层仍逐行绘制。计数、已报告长度和相似度加权有各自单位， 更不透明的连接不一定表示更强的独立同源证据。没有方向证据的点锚，不能因端点 相等就获得聚合方向。

当前转换边界

下一页给出只替换coord的实际例子。显式圆形半径、曲率、ring和径向序列标签位置在当前共线性合同中会被拒绝，而不是悄悄忽略。将这些坐标特有样式留给各自展示图；“任意组合完美转换”仍是长期目标，不是当前保证。

共线性默认只连接相邻显示行；要保持弦图的连接集合，需要在共同图层明确 adjacent_only = FALSE。显示方向可手动指定或交给coord自动判断，两种入口不能同时使用。

局部缺口与虚线

上下分链用 position_strand()；link_avoid = "smooth" 配合默认NULL gap，在箭头附近产生局部退让。跨行外框默认虚线；本例增大linewidth使其可见，不用显式linetype覆盖。此规则依据最终显示邻接，不表示反向比对。

比例尺为何曾经没对齐

geom_seq_scale() 的默认offset是横向2 mm、纵向6 mm，因此原图左端略向右偏移是明确配置，而非bp长度计算出错。本例使用 offset = unit(c(0, 10), "mm")，水平起点对齐左侧序列包络，纵向留出标签空间。本例采用水平居中，各行源坐标0不再相互对齐；比例尺对齐左侧包络，反向行的源坐标0还会移到另一端。比例尺衡量距离，不代表某个源区间。

默认表格列就够用

blastn -query query.fna -subject subject.fna -outfmt 6 -out result.tsv

guide_ggchord_legend() 控制离散角色图例，guide_ggchord_colourbar() 控制连续颜色 图例。colour/color 拼写别名保留，本文优先用 colour。图层 show.legend 决定显示，guides() 选择图例，theme(legend.position = ...) 决定位置。 过宽图例可分行或增加导出宽度，不需要删减生物学数据来迁就。

为场景选择主题

例子在 theme_variants 中保存 minimal、dark 和 plasmid 备选，按场景添加到相应图中。 上图使用 theme_ggchord_publication()，plasmid 预设用于圆图流程。 主题控制非数据外观，不选择坐标系，也不替代数据驱动的填色标度。 文字外观用 theme(text = element_text(...))；已删除的 base_size 式快捷参数见 迁移指南。

同一 query 的连接颜色一致；连续相似度应使用连续标度。固定颜色放在 aes() 外，图例必须能说明映射。

哪些参数支持

接口 支持参数 匹配范围
geom_seq() seq_radius, seq_curvature, seq_gap, seq_orientation 按序列；半径/曲率的效果取决于坐标模式
geom_seq_label() labels, seq_label_radius, seq_label_rotation, size, seq_label_hjust, seq_label_vjust 按序列；seq_label_orientation 是单个模式选项
geom_link_ribbon() / geom_link_line() link_gap 按端点所在序列；控制点不是逐序列标量
geom_gene() / geom_feature() width 按序列，或分别按 +/- 链
position_strand() / position_plasmid() offset 按序列或链；优先使用 Position 而非兼容 offset 入口
固定标签 geom_gene_label() / geom_feature_label() label_radial_offset, label_circum_offset, label_circum_limit, label_rotation 按序列或链；不代表所有文本参数都接受列表
position_track() 数值型 width, gap 原生布局数值可按序列；物理 unit() 使用单个绝对尺寸

seq_order 本身就是序列排列，不是上述值的循环规则。自动避让标签的 label_layout 是布局模式；手动角度和偏移请使用固定标签层，不把它们塞进自动标签的 ...。 axis/theme、aesthetic、标度、图例不继承这套列表扩展规则。手工标度本来就支持 按数据类别命名的颜色向量，那属于 ggplot2 的标度语义，见配色教程。

兼容写法与取舍

当前还兼容等长无名向量、按序列名的列表、按序号的列表及等长无名列表；gene/注释 的一项还可包含 +/- 两个值。它们是现有几何接口的兼容形式，不是任意参数的 通用容器。不同参数仍有自己的类型、长度、范围和单位检查。

v0.16.6 RC 审计决定保留这些等价形式，没有新增删除或弃用。位置写法跟随筛选后 当前显示序列顺序；名称匹配 accession ID 时优先按 ID。width/固定标签的逐序列 列表元素应为链值对，单值循环用 list(value)；Position offset 还允许逐序列单值 列表。显式按链命名的 Position offset 已带符号，未指定的链或序列补零； position_plasmid() 使用共享 offset，拒绝链值对。键应唯一；"1"、"+"、"-" 这类序列 ID 可能与序号或链简写混淆，按链设置时宜使用按序列命名的嵌套列表。 原生数值型 track width/gap 必须覆盖所有显示序列。这些规则不扩展到 theme。

数值并不共用一个单位：seq_gap 是比例，旋转角度以度表示，物理轨道尺寸使用 明确的 unit()。seq_backbone_gap、seq_backbone_width 是单值样式参数，不在 上述列表规则中。共线性自动方向用 coord_collinear(orientation = "auto")； geom_seq(seq_orientation = ...) 指定的是 +1/-1 数值方向。

layout_choice 以计数权重选择顺序/方向，因为本例的最小绘图表有意未保留比对长度统计列。 返回的选择应显式用于序列设置，不修改原图，也不确立生物学方向。 采用前应保存该选择并对照结果。文档精确尺寸见资产清单 (website/assets/plots.csv in the source repository)。

常见问题

调整尺寸后标签为什么不同？

可用物理空间改变了。使用显式尺寸预览与保存，并检查隐藏标签 诊断，不能由文字未显示直接推断输入行丢失。

旧参数为什么报错？

API 清理已删除旧别名的执行路径，见迁移表。同一语义不要混用新旧 写法。colour/color 函数拼写别名仍保留，文档优先使用 colour。

注释为什么不能作为 gene 绘制？

基因快捷层要求已知 +/- 链。未知链保留在通用注释层，不要猜成 +。 氨基酸区间需要显式投影。

直线模式的区间连接为什么没显示？

默认只连接相邻显示序列。应检查序列对选择、裁剪和校验结果，再有意使用明确 pairs 或 adjacent_only = FALSE。这个默认规则不删除原始输入记录。

包会计算比对或验证引物实验吗？

包可视化已有比对和计算搜索结果，不运行 BLAST、不由名称推断同源分组，也不验证湿实验 结果。搜索 confidence 不是概率。详见识别能力边界。

已测量诊断等于发布认证吗？

不等于。它描述一次指定渲染。平台、设备、字体、完整 vignette 和包检查属于明确授权 后的发布流程。验证范围见正式发布验收记录。

在哪里报告问题？

在 问题反馈页 提供小型输入、包与 ggplot2 版本、代码、目标宽高、设备和诊断结果。避免附带私有序列，通常可用合成数据复现。
