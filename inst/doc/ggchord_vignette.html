Links are coloured by query sequence ID using the backbone category palette; this does not encode identity or homolog groups. 1.1 Tables and field meanings

Learn the tables before selecting layers. Chord comparison was ggchord’s original core view. Its early BLAST workflows explain the compact field names retained today. A multi-sequence chord view displays existing interval comparisons among sequences; drawing does not run a multiple-sequence alignment algorithm.

Minimal shapes of three tables

Table Required columns One row represents
seq_data accver, length One sequence and its full length in bp
ribbon_data qaccver, saccver, qstart, qend, sstart, send One observed pair of aligned intervals
gene_data accver, start, end, strand One directed gene interval

Backbones alone need neither links nor genes. Use geom_feature() for annotations with unknown strand rather than assigning a direction.

Names and optional columns

accver originated from accession.version, but any stable contig identifier is allowed; versions are not added or removed. q means query and s means subject. Both IDs must occur in the sequence table.

pident is percentage identity, needed only for identity mapping/filtering. Alignment length differs from full sequence length. Keep evalue, bitscore, qlen and slen when required by an analysis. Gene anno is optional annotation text; supply it for labels. Additional category columns can feed aes() without becoming mandatory inputs.

Coordinates and directions

Use one-based inclusive bp coordinates. Genes have ordered bounds with a separate strand. Endpoint order can represent reverse alignments; do not sort every link. Maximum feature endpoints do not establish full sequence lengths. See the coordinate contract.

Understand each transformation

Filtering keeps observations meeting declared thresholds. Reciprocal-overlap deduplication selects a representative existing observation; it does not sum identities. Merging combines nearby compatible intervals into a display envelope. Bundling groups nearby query/subject locations into an aggregate. Inspect each $report and source-row membership, especially when extra metadata conflict. The merged or bundled envelope is not a newly computed nucleotide alignment. Estimated lengths retain their flags; unobserved identity is never invented.

Density is an explicit statistic

stat_ribbon_density() maps a computed density, and stat_ribbon_bundle() performs its explicit aggregation during build. The ordinary ribbon geom still draws one ribbon per row. Interpret count, reported length and identity weighting in their own units; more opaque ribbons need not mean stronger independently validated homology. A point anchor without direction evidence cannot acquire an aggregate orientation merely because its endpoints are equal.

Compatibility and design tradeoffs

Equal-length unnamed vectors, sequence-named lists, position-named lists and unnamed lists remain compatible. Gene/feature entries can additionally contain strand pairs. Each parameter still validates its own type, length, range and units. This does not make a list a valid container for any argument.

The v0.16.6 RC audit retains these equivalent forms: no deletion or deprecation is announced. Positional forms follow the current displayed sequence order after filtering; names take precedence when they match accession IDs. In width/fixed-label lists, a per-sequence entry is a strand pair; list(value) is the scalar recycling form. Position offsets also accept scalar entries per sequence. Explicit strand-named Position offsets are signed; an omitted strand or sequence uses zero. position_plasmid() uses one shared offset and rejects strand pairs. Native track width/gap must cover all displayed sequences. These rules do not extend to themes.

Numeric values do not all share one unit: seq_gap is a proportion, rotations are degrees, and physical track sizes use explicit unit() values. seq_backbone_gap and seq_backbone_width are scalar style controls, not members of the list rule. Frequently asked questions

Why are labels different after resizing?

The available physical space changed. Use explicit-size preview and saving. Check hidden-label diagnostics; do not infer missing input rows from absent text.

Why did an old parameter stop working?

The API cleanup removed execution of old aliases. Use the migration table. Do not mix old and new spellings for one semantic setting. The colour/color function spelling aliases remain, with colour preferred in documentation.

Why is a feature rejected as a gene?

The gene shortcut requires known +/- strand. Keep unknown strand in a general feature layer; do not guess +. Amino-acid intervals require explicit projection.

Why is a ribbon missing in linear mode?

By default ribbons connect adjacent displayed sequences. Inspect pair selection, clipping and validation. Use explicit pairs or adjacent_only = FALSE deliberately. This default does not remove original input records.

Can the package compute alignments or validate primer experiments?

It visualizes supplied alignments and computational search results. It does not run BLAST, infer clusters from names or validate wet-lab outcomes. Search confidence is not a probability. See recognition limitations.

Is a measured diagnostic a release certification?

No. It describes a requested render. Platform/device/font checks, full vignettes and package checks belong to an explicitly authorized release. See the release acceptance record for the actual scope of verification.

Where should I report a problem?

Use the issue tracker with a small input, package/ggplot2 versions, code, intended width/height, device and diagnostic output. Avoid attaching private sequence data; a synthetic reproduction is usually enough.
